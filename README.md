## Tech Stack

This portfolio is built with **pure HTML, CSS, and JavaScript** — no frameworks, no dependencies, no build tools required.

| Technology | Usage |
|------------|-------|
| HTML5 | Structure & semantic markup |
| CSS3 | Styling, animations, transitions, responsive layout |
| Vanilla JavaScript | Loader, cursor, scroll effects, counter animations |
| Google Fonts | Space Grotesk, Inter, JetBrains Mono |
| CSS Custom Properties | Theming and design tokens |
| Intersection Observer API | Scroll-reveal animations |
| requestAnimationFrame | Smooth cursor and counter animations |

## How to Run Locally

No setup needed. Just open the file:

```bash
# Option 1 — double-click the file
open index.html

# Option 2 — serve with Python
python -m http.server 8000
# then visit http://localhost:8000
```

---

## How to Deploy on GitHub Pages

1. Create a new repository named `<your-username>.github.io`
2. Upload `index.html` and `README.md`
3. Go to **Settings → Pages → Source → main branch → Save**
4. Your site will be live at `https://<your-username>.github.io`
